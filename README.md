# 🎯 نظام تقييم الأداء والتطوير الفردي (APES - Employee Development & Evaluation)
> منصة متقدمة لتخطيط وتطوير الموارد البشرية، قياس مؤشرات الأداء، وإدارة جلسات التوجيه المهني.

---

## 📋 نبذة عن النظام
نظام مخصص لإدارات التدريب والتطوير البشري، يطبق أفضل الممارسات الإدارية العالمية في تقييم الموظفين من خلال خطط التطوير الفردية، مؤشرات الأداء، جلسات التوجيه (GROW Coaching)، وسجلات الوقائع الحرجة.

## ✨ الميزات الرئيسية
* **خطط التطوير الفردي (IDP):** صياغة أهداف تطويرية وجداول زمنية لتحسين كفاءة الموظف.
* **مؤشرات الأداء والأهداف (Goals & KPIs):** قياس دقيق للمخرجات ومستويات الإنجاز الفردية والمؤسسية.
* **جلسات التوجيه بنموذج GROW:** توثيق جلسات التدريب والإرشاد المهني بين المدربين والموظفين.
* **خطط تحسين الأداء (PIP):** إدارة برامج معالجة جوانب القصور ومتابعة نتائجها.
* **سجل الوقائع الحرجة (Critical Incident Log):** توثيق السلوكيات والمواقف المميزة أو السلبية بالتواريخ والشهادات.
* **تحليل SWOT المهني:** تحليل نقاط القوة، الضعف، الفرص، والتحديات للكادر.

## 🛠️ التقنيات المستخدمة
* **Framework:** Laravel 11
* **Language:** PHP 8.4
* **Database:** MySQL / SQLite
