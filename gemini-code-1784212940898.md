# نظام إدارة وتمكين الأداء الفعال والمستمر (Active Performance & Enablement System - APES)

يهدف هذا النظام الرقمي المتكامل والمبني بإطار العمل **Laravel** وحزمة **Filament PHP** الإدارية إلى سد "فجوة التنفيذ" في المؤسسات. يرتكز النظام على تحويل الخطط الإستراتيجية إلى سلوك يومي ملموس لفرق العمل، والانتقال من التقييم العاطفي القائم على الانطباعات الشخصية والولاءات إلى الإدارة بالدليل الرقمي ومؤشرات الأداء (KPIs) وسجل الوقائع المرصودة.

### 1. تحليل SWOT الإستراتيجي
يربط النظام أهداف الموظفين بنقاط القوة والضعف الداخلية للمؤسسة، والفرص والتهديدات الخارجية، لضمان صياغة أهداف تخدم التوجه الإستراتيجي العام وتساهم في صنع سياسات مبنية على الأدلة[cite: 365].

### 2. بطاقة الأداء المتوازن (Balanced Scorecard - BSC)
توزيع الأهداف عبر أربعة أبعاد مترابطة سبباً ونتيجة (التعلم والنمو $\rightarrow$ العمليات الداخلية $\rightarrow$ العملاء $\rightarrow$ المالي/الإستراتيجي)[cite: 616, 617, 618, 619]:
* **قوانين الأوزان النسبية:** لضمان الجدية ومنع احتكار الجهد، يفرض النظام حداً أدنى لوزن أي هدف $10\%$ وحداً أقصى $30\%$، بمجموع تراكمي يساوي $100\%$ بالضبط لكل بطاقة موظف فردية[cite: 670, 671, 672].
* **مؤشرات قيادية ومتأخرة (Leading & Lagging):** التوازن بين المؤشرات التي تقيس نتائج الماضي والمؤشرات الاستباقية التي تسمح بالتدخل الفوري وتوقع النجاح[cite: 555, 556].

### 3. لغة الحوار السلوكي والكوتشينج (GROW & SBI)
* **نموذج GROW:** يمنع النظام القفز المباشر من الهدف إلى البدائل قبل التشخيص الدقيق والعميق للواقع الحالي بالأرقام[cite: 265, 285].
* **نموذج SBI (Situation-Behavior-Impact):** صياغة التغذية الراجعة من خلال تحديد الموقف بدقة، وصف السلوك المرصود فقط دون أحكام هجومية، وشرح الأثر المباشر على العمل[cite: 887, 888, 890, 931].

### 4. سجل الوقائع الحرجة (Critical Incident Log)
يعمل النظام كـ "درع للموظف" يحميه من أثر الحداثة (Recency Bias) الذي يجعل التقييم السنوي رهينة لآخر أسبوعين فقط[cite: 50, 54, 72]. يعتمد التوثيق على مواقف مشهودة بدلاً من الانطباعات العاطفية[cite: 51, 53].

### 5. خطط التطوير الفردية (IDP) وخطط تحسين الأداء (PIP)
* **IDP:** لفرز الطاقات البشرية، وتوطين المعرفة، وتطوير الكوادر الواعدة لضمان الاستبقاء[cite: 14, 388, 395].
* **PIP:** الملاذ الإداري الأخير لمعالجة التعثر من خلال مستهدفات صارمة بمهل زمنية واضحة (30-60-90 يوماً) مع تحديد مسؤولية الإدارة في الدعم والتمكين[cite: 1006, 1009, 1010].

ثالثاً: منطق التحقق والذكاء البرمجي (Backend Business Logic)يحمي منطق النظام جودة المدخلات ويحسب المؤشرات التراكمية تلقائياً:1. التحقق الإداري من الأوزان النسبية للبطاقة الفرديةيمنع حفظ أي هدف جديد للموظف إذا كان مجموع أوزان الأهداف يتجاوز $100\%$ أو يخرق الحدود المفروضة:  

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;
use Illuminate\Support\Facades\DB;

class StoreGoalAndKpiRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;
    }

    public function rules(): array
    {
        return [
            'user_id' => 'required|exists:users,id',
            'perspective' => 'required|in:learning_growth,internal_processes,customer,financial_strategic',
            'smart_goal_text' => 'required|string|min:15',
            'weight' => 'required|numeric|min:10|max:30', // حد أدنى 10% وحد أقصى 30% لضمان التوازن والتركيز
            'baseline' => 'required|numeric|min:0',
            'target' => 'required|numeric|gt:baseline', // هدف متمدد يتجاوز خط الأساس
            'kpi_type' => 'required|in:leading,lagging',
        ];
    }

    public function withValidator($validator)
    {
        $validator->after(function ($validator) {
            $userId =$this->input('user_id');
            $newWeight =$this->input('weight');

            $currentTotalWeight = DB::table('goals_and_kpis')
                ->where('user_id', $userId)
                ->sum('weight');

            if ($currentTotalWeight + $newWeight > 100.00) {$validator->errors()->add(
                    'weight', 
                    "مجموع الأوزان الحالية للموظف هو {$currentTotalWeight}\%. إضافة هذا الهدف بوزن {$newWeight}% يتجاوز الحد الأقصى الرياضي المسموح به (100%)!"
                );
            }
        });
    }
}

2. محرك التراكم المركب لفلسفة "كايزن" (1% يومياً)حساب الأثر الحسابي لتطوير الأداء بنسبة $1\%$ يومياً أو تراجعه بالمعادلة الرياضية للتراكم المركب لإظهاره داخل لوحات الموظفين:  

namespace App\Services;

class KaizenCompoundService
{
    /**
     * حساب التراكم الإيجابي والسلبي للموظف
     * (1.01)^365 = 37.78 (تحسن متراكم)
     * (0.99)^365 = 0.03 (تراجع نحو الصفر تقريباً)
     */
    public function getKaizenProjections(float $dailyImprovementRate = 0.01, int$days = 365): array
    {
        $positiveMultiplier = pow(1 +$dailyImprovementRate, $days); // (1.01)^365$negativeDecline = pow(1 - $dailyImprovementRate,$days); // (0.99)^365

        return [
            'improvement_factor' => round($positiveMultiplier, 2), // 37.78 ضعفاً بنهاية العام
            'decline_floor' => round($negativeDecline, 2), // 0.03 (تراجع للصفر تقريباً)
        ];
    }
}

3. الفحص والتوصية الآلية بخطط التطوير أو التحسين
يفحص النظام أداء الموظفين دورياً لإطلاق إنذار مبكر للكوتش لجدولة خطة تحسين أداء (PIP) في حال التعثر، أو فتح خطة تطوير فردي (IDP) للتميز لضمان الاستبقاء:

namespace App\Services;

use App\Models\User;
use App\Models\PerformanceImprovementPlan;
use App\Models\IndividualDevelopmentPlan;

class AutomatedCalibrationService
{
    public function evaluateEmployeePath(User $user): array
    {
        $averageAchievement =$user->goalsAndKpis()->avg('current_progress_rate') ?? 0;
        $negativeIncidents =$user->criticalIncidents()->where('type', 'negative')->count();
        $positiveIncidents =$user->criticalIncidents()->where('type', 'positive')->count();

        // 1. إذا كان الأداء منخفضاً وتراكمت السلوكيات السلبية
        if ($averageAchievement < 80.00 \vert{}\vert{}$negativeIncidents >= 3) {
            return [
                'recommendation' => 'PIP_REQUIRED',
                'reason' => "الموظف متعثر في الأداء الفعلي (نسبة الإنجاز {$averageAchievement}\%) مع رصد {$negativeIncidents} وقائع حرجة سلبية.",
            ];
        }

        // 2. إذا كان الموظف متميزاً ويتجاوز التوقعات (تمكين واستبقاء)
        if ($averageAchievement >= 115.00 &&$positiveIncidents >= 3) {
            return [
                'recommendation' => 'IDP_UPGRADE',
                'reason' => "أداء متميز واستثنائي (نسبة الإنجاز {$averageAchievement}\%) مع رصد {$positiveIncidents} وقائع إيجابية متتالية.",
            ];
        }

        return [
            'recommendation' => 'MAINTAIN_COACHING',
            'reason' => 'الأداء ضمن النطاق الآمن المستهدف. استمر في جلسات التوجيه ربع السنوية.',
        ];
    }
}

            ]);

    public static function table(Tables\Table $table): Tables\Table
    {
        return $table
            ->columns([
                Tables\Columns\TextColumn::make('user.name')->label('الموظف')->searchable(),
                Tables\Columns\TextColumn::make('career_goal')->limit(30)->label('الهدف التمكيني'),
                Tables\Columns\BadgeColumn::make('status')

                        'secondary' => 'draft',
                        'primary' => 'active',
                        'success' => 'completed',
                        'danger' => 'suspended',
                    ])->label('حالة الملف'),
                Tables\Columns\TextColumn::make('end_date')->date()->label('تاريخ المراجعة'),
            ])
            ->filters([
                Tables\Filters\SelectFilter::make('status')
                    ->options([
                        'draft' => 'مسودة',
                        'active' => 'نشط',
                        'completed' => 'مكتمل',
                    ])
            ]);
    }
}

خامساً: إطار التقييم المتوازن ومعايرة الأداء (9-Box Grid Calibration)يقوم النظام بدمج الأداء الفعلي المستخرج من الـ KPIs مع نتائج الـ IDPs لتوليف مصفوفة المربعات التسعة (9-Box Grid) لتحديد المواقع الاستراتيجية وتوجيه الطاقات البشرية للأماكن الأكثر إنتاجية:  

التقييم الفعلي (KPIs),إمكانات النمو والتطوير (IDP) - منخفض,إمكانات النمو والتطوير (IDP) - متوسط,إمكانات النمو والتطوير (IDP) - مرتفع
مرتفع (يتجاوز الأهداف),موظف تقني أساسي (حامي العمليات اليومية),نجم صاعد (مرشح لإدارة القسم),قائد مستقبلي موجه (الصف الأول)
متوسط (يلتزم بالحد الأدنى),موظف منجز للعمليات الأساسية فقط,موظف ذو أداء مستقر وقابل للتوجيه,كادر واعد ذو إمكانيات غير مستغلة
منخفض (أقل من المتوقع),موظف متعثر (إخضاع فوري لـ PIP لمدة 30 يوماً),موظف حديث العهد بحاجة لأمان نفسي ورعاية,موظف في المكان غير المناسب (إعادة توجيه)

سادساً: خارطة طريق التدشين والتنفيذ (Deployment Roadmap)
لضمان نجاح المنظومة وإطلاقها بشكل يضمن تفاعل الكوادر البشرية، نتبع المراحل الإدارية الأربعة التالية:

[كانون الثاني]              [شهرياً/أسبوعياً]             [ربع سنوي]             [نهاية العام]
  التخطيط                  المتابعة والتوثيق             التوجيه والتصحيح         التقييم العادل
 (بناء أهداف SMART)    (سجل الوقائع الحرجة - SBI)     (جلسات GROW و 30 دقيقة)    (مكافآت وخطط IDP)

 مرحلة التوافق الإستراتيجي (شهر كانون الثاني): صياغة الأهداف الفردية SMART وضبط خطوط الأساس والمستهدفات السنوية بدقة على النظام مع حوكمة أوزان BSC.  مرحلة الشراكة والمتابعة اليومية المستمرة (طوال العام): التزام الكوتش بفتح سجل الوقائع الحرجة لتسجيل السلوكيات الفورية وتوجيه رسائل التغذية الراجعة عبر أسلوب الشطيرة ونموذج SBI لخفض الدفاعات النفسية وتوفير قاعدة صلبة للتقييم السنوي العادل.  مرحلة المعايرة ومراجعة النبض (ربع سنوية): لقاء الـ 30 دقيقة الذهبي لحل المشكلات بمراجعة الأرقام لمدة 10 دقائق ، ثم تحليل العقبات التشغيلية دون لوم شخصي لـ 10 دقائق ، ووضع خطة العمل للربع القادم في آخر 10 دقائق ، مع الاستعانة بنموذج GROW للتوجيه.  مرحلة الحصاد العادل وتأهيل الصف الثاني (نهاية السنة): تقييم مؤشرات الأداء السنوية بالاعتماد الكلي على حقائق سجل الوقائع ، ومن ثم ترقية الكوادر المتميزة إلى خطط IDP ، وتصحيح مسار المتعثرين بوثائق PIP قانونية وموضوعية وسلوكيات واضحة للتحسن.

 بهذا نكون قد دمجنا المعارف الإدارية لـ (GIZ) والتحول الاقتصادي [cite: 343, 345, 362]، وطوعنا البرمجة لتأسيس نظام رقمي صلب ومرن ينهي فجوة التنفيذ، ويبني ثقافة الجدارة والقرارات المبنية على الأرقام والدليل المادي[cite: 10, 11, 12].
